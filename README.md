# Wealth Tax Watch

Biweekly global briefing on wealth tax proposals, public opinion and international tax cooperation, published for the Global Tax Fairness Fellowship cohort.

- **Issue 01:** September 1-23, 2026
- **Live site:** https://wealth-tax-watch.vercel.app

## Structure

A single self-contained `index.html` (inline CSS, inline SVG flags and logo, Archivo from Google Fonts). No build step.

## Publishing a new issue

Replace `index.html` with the new issue and push. If this repository is connected to the Vercel project `wealth-tax-watch`, each push to `main` redeploys the site automatically.
